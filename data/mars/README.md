# Mars data status

The candidate list contains no Mars target location or coordinates. Therefore no MOLA elevation or USGS Mars geology unit is reported as a site measurement. The project cites the NASA MOLA MEGDR archive and USGS Global Geologic Map of Mars as potential regional products, but no raster or map point has been selected or processed. Global planetary facts in `../../planetary_facts.csv` do not represent local conditions at a selected Mars site.
