# Processed terrain and geology

`site_terrain_geology.json` contains reproducible elevation point samples and map-unit intersections for the eight approximate Earth candidate points. The source samples, exact query coordinates, API URLs, product and service resolution fields, units, processing footprint, derivative methods, map scales, and map citations are retained in the output. Regenerate it with `python process_site_terrain_geology.py`; network/source failures are recorded and cause a nonzero exit.

USGS EPQS exposes 3DEP elevations for the two listed U.S. points; its point response does not provide a vertical datum and returns a service resolution code and raster ID. Each U.S. point is therefore isolated into its own comparison group. Other points use the Copernicus DEM GLO-90 2021 release through Open-Meteo's 90 m elevation API. All terrain metrics use the same 3×3 point spacing and footprint, but values from different products or resolution groups are not treated as directly comparable.

Geology is a Macrostrat map-point intersection with the returned map scale and original source citation. The point coordinates are approximate and the mapped products vary in scale; coarse map intersections are regional context, not field-verified site geology. No Moon or Mars target coordinates are present, so LOLA/MOLA site elevations and planetary site geology are explicitly unavailable. No similarity score or ranking is produced.
