# Earth climate products

This directory contains a NASA POWER daily API snapshot for the eight approximate candidate coordinates, covering 2023-01-01 through 2024-12-31. Each site has 731 returned date records; `download_errors.json` records any failed requests (none for this snapshot). The daily CSV, summary CSV/JSON, and metadata JSON are generated by running `python download_real_climate.py` from the repository root in a networked Python 3 environment.

NASA POWER values are gridded modeled/reanalysis-derived estimates, not in-situ observations. Missing and sentinel values remain blank/null, and aggregates use only valid returned values. This download does not create terrain or geological measurements. See [METHODS.md](../../METHODS.md) for variable units, coverage rules, and limitations.
